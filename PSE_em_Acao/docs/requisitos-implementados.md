# Requisitos implementados

- RF01: cadastrar ação com código, escola, tema, data, público-alvo, responsável e quantidade prevista.
- RF02: listar ações cadastradas.
- RF03: pesquisar por código, escola ou tema.
- RF04: atualizar situação para planejada, realizada ou cancelada.
- RF05: registrar participantes efetivos em ações realizadas.
- RF06: gerar resumo quantitativo por situação e participação.
- RF07: validar campos obrigatórios, códigos duplicados, datas, quantidades e opções.
- RNF01: implementação em C para terminal.
- RNF02: menus e mensagens textuais.
- RNF03: validação de entradas.
- RNF04: orientação para dados fictícios e coletivos, sem dados clínicos individuais.
- RNF05: decomposição em funções.
